# atividade-16-10
atividade pratica

Cadastro com interface gráfica deverão desenvolver uma aplicação desktop que cadastre e liste objetos de uma classe criada anteriormente.
1) Desenvolva um aplicativo desktop em Python utilizando Tkinter e Programação Orientada a Objetos. Escolha um domínio, como cadastro de livros, alunos, produtos ou veículos, e crie uma classe com pelo menos 3 atributos, incluindo um atributo protegido com validação utilizando @property e @atributo.setter.
 Em seguida, desenvolva uma interface gráfica utilizando uma classe para representar a janela, contendo componentes Label, Entry e Button, organizados com pack() ou grid().
 O aplicativo deverá permitir cadastrar objetos, validar os campos preenchidos, armazenar os cadastros em uma lista de objetos e apresentar os registros utilizando Listbox ou Treeview. Utilize messagebox para informar erros e confirmar os cadastros realizados.
